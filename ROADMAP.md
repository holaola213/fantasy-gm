# Fantasy GM Roadmap

The current V1 priority is a useful manual draft assistant for one user and one
ESPN fantasy basketball league. Later items are directional possibilities, not
committed implementation promises.

## Completed

- Milestone 0 - Infrastructure
- Milestone 1 - Players
- Milestone 2 - League Configuration
- Milestone 3 - Normalized Player Projections
- Milestone 4 - Draft State
- Milestone 5 - Replacement-Level Valuation
- Milestone 6 - Draft Assistant MVP
- Milestone 7 - Draft Intelligence

## Next

- Milestone 8 - Recommendation Logic

## Later

- Real projection imports
- Multiple-source aggregation
- NBA schedule and injury data
- In-season fantasy rosters
- Waiver and streaming recommendations
- Trade analysis
